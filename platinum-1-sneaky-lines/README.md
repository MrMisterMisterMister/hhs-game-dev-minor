# Sneaky Lines - Artificial Intelligence Platinum 1 Achievement
Expanded version of Gold 2 Dungeons.

## Features
- A simple free-look camera, only while maze is generating.
	- Use WASD to move the camera.
	- Hold LEFT MOUSE BUTTON to rotate the camera.
	- Use SCROLL WHEEL to increase and decrease movement speed.
- Simple player movement.
	- Use WASD to move.
- A dungeon generator.
- Aspiring dragons:
	- Stand in their FOV and they will eat you.
	- Hide behind walls to avoid the FOV.
- Expandable dungeons (which can be done in the editor; make sure to turn off avoidance).
