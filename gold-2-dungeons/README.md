# Dungeons - Artificial Intelligence Gold 2 Achievement
A basic dungeon generator inspired by [quwatz_].

## Features
- A simple free-look camera
	- Use WASD to move.
	- Hold LEFT MOUSE BUTTON to rotate the camera.
	- Use SCROLL WHEEL to increase and decrease movement speed.
- A Dungeon Generator.
- A Control Panel to generate the dungeon.
