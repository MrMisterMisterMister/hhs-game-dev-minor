# Shaders - Effects & Shaders Gold 1 Achievement
Three basic shaders using vertex and fragment shaders.

## Features
- A simple free-look camera
	- Use WASD to move.
	- Hold LEFT MOUSE BUTTON to rotate the camera.
	- Use SCROLL WHEEL to increase and decrease movement speed.
- Three shaders.
