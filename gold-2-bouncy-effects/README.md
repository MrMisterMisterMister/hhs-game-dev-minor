# Bouncy Effects - Effects and Shaders Gold 1 Achievement
Added juicy effects for a bouncy ball game.

## Features
- A trail renderer follows both balls.
- Tile gets highlighted whenever it gets toggled after a collision.
- Particle effect whenever a ball bounces off of something.
- Screen shake effect whenever a ball bounces off of something.
- Ball gets squashed after collision.
- Screen flash after after a tile gets toggled.
